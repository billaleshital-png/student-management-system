# 🎓 Student Data Management System

## 📌 Project Description

Student Data Management System is a simple Python-based application used to manage student records.

The application allows users to add, view, search, update, and delete student information. It also provides features to calculate average marks and find the top-performing student.

Student data is stored in a CSV file for easy access and management.

---

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by Roll Number
- ✏️ Update Student Details
- 🗑️ Delete Student
- 📊 Calculate Average Marks
- 🏆 Find Top Student
- 💾 Store student data in CSV file
- ⚠️ Validate marks between 0 and 100

---

## 🛠️ Technologies Used

- Python 3
- CSV File Handling
- Functions
- Loops
- Dictionaries
- Conditional Statements
- Exception Handling
- File Handling
